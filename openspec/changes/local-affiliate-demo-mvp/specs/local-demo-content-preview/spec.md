# Spec Delta

## Purpose

讓使用者不需連接外部平台或設定服務，即可在本機體驗選取示意商品、設定內容偏好，以及查看明確標示為模擬的推薦與文案預覽。

## ADDED Requirements

### Requirement: 使用者可瀏覽並選擇示意商品
展示流程 MUST 提供清楚標示為合成資料的商品項目，允許使用者選取最多三項供本機預覽使用，且不得將示意選取當成正式商品資格或批次。

#### Scenario: 選取示意商品
- **WHEN** 使用者在本機展示流程選取一項示意商品
- **THEN** 系統顯示選取狀態，並允許使用者繼續設定內容偏好

#### Scenario: 超過展示商品上限
- **GIVEN** 使用者已選取三項示意商品
- **WHEN** 使用者嘗試再選取另一項
- **THEN** 系統保留原選取並說明展示流程最多選取三項

### Requirement: 展示偏好只用於本機模擬
展示流程 MUST 允許使用者設定分享對象、內容主題、文字語氣與文案風格；保存偏好時 MUST 明確告知其儲存範圍，不得要求資料庫或登入。

#### Scenario: 儲存本機偏好
- **WHEN** 使用者完成偏好設定並繼續展示流程
- **THEN** 系統使用該偏好產生本次預覽，並將偏好保存在目前瀏覽器

#### Scenario: 偏好服務未設定
- **GIVEN** 正式偏好 API 或資料庫不可用
- **WHEN** 使用者進入展示偏好設定
- **THEN** 系統仍允許使用者選擇本機示範模式並完成設定

### Requirement: 模擬內容須清楚標示且不冒充真實資料
系統 MUST 依選取商品與使用者偏好提供推薦理由及文案預覽，並明確標示這些內容是模擬輸出而非真實 AI；商品資訊及分潤數字也 MUST 標示為示意資料。

#### Scenario: 查看模擬推薦與文案
- **WHEN** 使用者完成商品選擇與偏好設定並產生預覽
- **THEN** 系統顯示對應所選商品及偏好的推薦理由與文案，並可見「模擬輸出」及「非真實 AI」標示

#### Scenario: 防止誤認為可發布的商品資訊
- **WHEN** 使用者查看示意商品或其文案預覽
- **THEN** 系統說明商品、價格、分潤及未核實主張僅供展示，發布前需自行查證並揭露分潤關係

### Requirement: 使用者可搜尋與篩選示意商品
展示流程 MUST 允許使用者以文字搜尋示意商品，並依商品分類篩選；搜尋及篩選不得更改商品資料或正式商品資格。

#### Scenario: 搜尋商品
- **WHEN** 使用者輸入商品名稱或描述中的關鍵字
- **THEN** 系統只顯示符合關鍵字的示意商品，並提供清除搜尋的方式

#### Scenario: 依分類篩選商品
- **WHEN** 使用者選擇一個商品分類
- **THEN** 系統只顯示該分類的示意商品，且可清除分類篩選

### Requirement: 本機保存展示選品與預覽紀錄
展示流程 MUST 在目前瀏覽器保存已選示意商品與已產生的模擬預覽，供使用者重新檢視；該紀錄不得建立正式批次或上傳至伺服器。

#### Scenario: 回看已保存預覽
- **WHEN** 使用者重新開啟展示流程且瀏覽器內已有有效的展示紀錄
- **THEN** 系統允許使用者重新檢視已保存的商品、偏好與模擬文案

#### Scenario: 本機紀錄無法讀取
- **GIVEN** 瀏覽器儲存內容格式無效或不可用
- **WHEN** 展示流程載入本機紀錄
- **THEN** 系統明確提示紀錄無法載入，並允許使用者開始新的展示流程

### Requirement: 可複製或下載模擬文案
系統 MUST 允許使用者複製單則預覽文案或下載文字檔，並在輸出中保留模擬標示與必要揭露文字。

#### Scenario: 複製預覽文案
- **WHEN** 使用者選擇複製文案
- **THEN** 系統將完整文案複製到剪貼簿並回報操作結果

#### Scenario: 下載預覽文案
- **WHEN** 使用者選擇下載文案
- **THEN** 系統下載純文字檔，內容保留模擬標示、未核實資料警語與分潤揭露提醒

### Requirement: 可檢視商品詳情及推薦理由
展示流程 MUST 允許使用者查看選取示意商品的完整示意資訊及其依偏好產生的模擬推薦理由，且不得將模擬資訊呈現為已核實事實。

#### Scenario: 開啟商品詳情
- **WHEN** 使用者開啟示意商品的詳情
- **THEN** 系統顯示商品描述、示意售價、示意分潤及示意資料警語

#### Scenario: 詳情顯示個人化推薦理由
- **GIVEN** 使用者已設定內容偏好
- **WHEN** 使用者查看商品詳情
- **THEN** 系統顯示依該偏好組合且標明為模擬的推薦理由
