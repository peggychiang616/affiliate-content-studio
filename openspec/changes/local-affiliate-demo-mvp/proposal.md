# Proposal

## Why

完整的商品分潤內容製作流程仍依賴尚未核實的商品來源、素材權利及生成服務，無法直接作為免設定的本機展示版。現有網站已具備合成商品、瀏覽器本機偏好與模板文案流程；本變更以這個可操作版本作為明確、可提交的 MVP，避免把模擬結果誤認為正式服務。

## What Changes

- 定義可不連資料庫、登入或 API Key 使用的本機展示流程：選擇最多 3 個合成商品、設定內容偏好、查看推薦理由與文案預覽。
- 加入商品搜尋與分類篩選、商品詳情、本機選品及預覽紀錄，以及文案複製／下載，讓展示流程可持續操作與回看。
- 明確標示示意商品與文案為模擬輸出；偏好僅保存在使用者目前的瀏覽器。
- 使用不綁定特定業者的「電商平台」通用措辭。
- 保留既有正式商品資格檢查及批次 API；本機示範不繞過這些正式流程的防護。
- 將影片渲染、MP4、配音、真實 AI／電商平台串接、七日排程、完整報表及正式部署列為本 MVP 範圍外。

## Capabilities

### New Capabilities

- `local-demo-content-preview`: 定義合成商品選取、本機偏好設定，以及清楚標示為模擬輸出的推薦理由與文案預覽。

### Modified Capabilities

None.

## Impact

- 對應既有 Next.js 首頁、商品目錄、本機偏好工具、展示流程測試、README 與提交說明。
- 不新增服務、資料庫需求、外部 API 或相依套件。
- 既有正式製作 API 和權利／資格檢查維持原狀；展示流程不會建立正式批次或媒體輸出。
