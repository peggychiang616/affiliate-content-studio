# Spec Delta

## Purpose

確保內容製作只使用資料可追溯、狀態有效且商品素材權利已核實的商品，讓使用者能在選品前知道哪些商品可安全進入製作流程。

## ADDED Requirements

### Requirement: 商品可製作狀態可查
系統 MUST 為每項商品記錄其來源、可支持的商品事實、資料更新時間及資格狀態，並在選品時顯示可製作或不可製作的原因。

#### Scenario: 顯示已核對商品
- **GIVEN** 商品有可追溯來源、有效資料及符合資格的狀態
- **WHEN** 使用者瀏覽可用商品池
- **THEN** 系統顯示商品及資料日期，並允許選入製作批次

#### Scenario: 商品資料或資格不足
- **GIVEN** 商品缺少來源、必要資料或有效資格
- **WHEN** 使用者瀏覽商品池或嘗試選取該商品
- **THEN** 系統標示不可製作及可理解的原因，且不允許該商品進入批次

### Requirement: 素材權利可核對
系統 MUST 為每項商品圖片或影片保留來源及使用權範圍；使用權未知、缺漏、過期或不涵蓋預定改作與匯出時，不得將該素材用於輸出。

#### Scenario: 素材權利涵蓋用途
- **GIVEN** 素材有可核對的來源、權利提供者、有效期限及涵蓋用途
- **WHEN** 系統檢查商品是否可製作
- **THEN** 系統只允許使用符合本次剪輯與匯出用途的素材

#### Scenario: 素材權利無法確認
- **GIVEN** 素材權利未知、資料不完整、已失效或不涵蓋本次用途
- **WHEN** 使用者啟動製作或匯出
- **THEN** 系統阻擋受影響商品或內容，並說明缺少或失效的權利資訊

### Requirement: 製作前重新檢查就緒狀態
系統 MUST 在製作及匯出前重新確認商品資料、資格與素材權利仍有效；狀態變更只阻擋受影響商品及其成果。

#### Scenario: 已選商品在製作前失效
- **GIVEN** 使用者已選取商品，但其資料、資格或素材權利在啟動前已失效
- **WHEN** 使用者開始批次製作
- **THEN** 系統阻擋該商品並說明原因，且不以其他商品替代

#### Scenario: 匯出前權利狀態改變
- **GIVEN** 已產生內容，但所用商品或素材在匯出前變為不可用
- **WHEN** 使用者確認匯出
- **THEN** 系統阻擋受影響成果，保留其他有效成果，並指出需重新核對的項目
