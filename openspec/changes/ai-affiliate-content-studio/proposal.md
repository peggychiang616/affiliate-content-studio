# Proposal

## Why

剛開始做蝦皮分潤的上班族，選定商品後仍可能需要自行整理賣點、撰寫貼文、剪輯短片及安排發布內容。本變更探索以少量操作取得可核對、可確認的配套內容是否能減少整段人工作業；需求、品質、資料與素材權利、成本及付費意願都尚未驗證，因此先做受控 MVP，不把產量或生成成功當成商業成效。

## What Changes

- 建立響應式 Web MVP，讓使用者從可用商品池選品，檢查商品資料與素材權利後啟動內容製作。
- 每批最多處理 3 個商品、每商品 2 個敘事版本；每組產生一則繁體中文貼文及一支使用授權素材製作的 15–30 秒直式短片。
- 提供批次進度、逐組預覽、文字／預設風格修改、單組重生成、失敗局部重試，以及確認後匯出；不得以其他商品替代失敗組，也不得自動發布。
- 為已確認內容提供七日建議安排，可修改日期、順序或取消；不自動發布，無足夠合格內容時明示缺額。
- 記錄商品與素材來源、版本、權利狀態、生成與重試、確認、匯出、錯誤及成本所需事件，支持 V0–V3 的品質、效率、再使用與付費驗證。
- 先驗證蝦皮商品資料取得、素材再利用權、配音／音樂／字體權利、生成與渲染服務 API 及成本；未確認前不得把商品或素材標為可製作，也不宣稱已可串接。
- 不包含自動發布、全新生成商品畫面、分潤收入試算（留待 Next）、擴大商品搜尋或以 AI 生成結果推論訂單／收入。

## Capabilities

### New Capabilities
- `affiliate-product-readiness`: 管理可選商品的已核對事實、資料新鮮度、素材來源與使用權；不明或失效時阻擋製作與匯出。
- `batch-content-production`: 依商品事實與有權使用的素材批次產生貼文和短片，支援審閱、局部修改／重試、確認及匯出，並保留可追溯狀態。
- `content-planning-calendar`: 僅將已確認內容安排在未來七日，允許調整與保存，不自動發布。

### Modified Capabilities

None.

## Impact

- 新增綠地響應式 Web 應用；目前 repository 沒有應用程式碼、既有架構、測試或依賴可沿用。
- 可能需要蝦皮商品資料來源、具權利紀錄的商品素材、文字生成、配音、字幕與影片渲染服務；其 API、授權及成本均待 V0 確認，不預設特定供應商。
- 涉及商品與素材權利驗證、事實主張可追溯、批次狀態／冪等局部重試、可下載媒體、使用者時區與七日安排。
- 依 MVP 驗證門檻決定是否進入有限試用；需在測試前確定資料存取、權限、保留期限與刪除機制，且不索取平台帳密。
