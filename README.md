# Affiliate Content Studio

響應式聯盟行銷內容工作室 MVP，提供本機商品選取、偏好設定與模擬文案預覽。

## 本機啟動

需求：Node.js 20.9 以上、npm。

```bash
cd web
npm install
npm run dev
```

開啟 <http://localhost:3000>。首頁展示不需資料庫或 API Key 的本機流程；商品、分潤與文案皆為合成示意資料，不代表真實平台資訊或已核准內容。
